# Kova Studio

Portfolio and company site for Kova — a boutique studio building web applications, websites, and mobile experiences.

## What it is

- **Studio showcase** — services, selected work, and team
- **Portfolio** — real projects with descriptions and tech breakdowns
- **Contact point** — for potential clients to reach out

## Getting started

```bash
npm install
npm run dev
```

## Deployment

Deployed to Vercel. Any push to `main` triggers a production build.
